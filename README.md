# Система управления складом и каталогом товаров

Лабораторная работа по ООП на Java:
классы, наследование, паттерны «Фабричный метод» и «Итератор».

## Возможности

* склад (Warehouse) с ограничением максимального количества товаров;
* обход товаров через собственный итератор (работает в цикле for-each); создание товаров через фабрики;
* добавление, удаление (по ID и по индексу), поиск (по ID, категории, цене);
* глубокое копирование склада и перемещение товаров между складами;
* классы-атрибуты Price, Quantity, Weight с проверкой на неотрицательные значения.

## Архитектура

### Иеархия товаров

```
Product
├── electronics/           Smartphone, Laptop
├── clothing/              TShirt, Jacket
└── food/                  Milk, Bread
```

#### Каждый товар имеет:

1) Базовые поля:

   | Поле       | Тип        | Описание                                         | 
   |------------|------------|--------------------------------------------------|
   | `id`       | `int`      | уникальный номер, выдается статическим счетчиком |
   | `name`     | `String`   | название                                         |
   | `category` | `String`   | `Electronics`, `Clothing` или `Food`             |
   | `price`    | `Price`    | цена в доллараx                                  |
   | `quantity` | `Quantity` | остаток на складе                                |
   | `weight`   | `Weight`   | вес в граммах                                    |

2) Действия:

   | Название метода              | описание                                 |
   |------------------------------|------------------------------------------|
   | `transferTo(Storage other)`  | Перенос товара из одного склада в другой |
   | `setPrice(Price newPrice)`   | Замена старой цены на новую              |
   | `changeQuantity(int delta)`  | Изменение количество товара              |
   | `clone()`                    | копирование товара                       |

### Классы-атрибуты
`Price`, `Quantity` и `Weight` инкапсулируют значение и проверяют его при создании и 
изменении. Отрицательное значение приводит к `IllegalArgumentException`. У `Quantity`
дополнительно есть `changeQuantity(int delta)`: остаток не может уйти в минус.

### Паттерн: Factory Method

`ProductFactory` — абстрактный создатель с методом создания товара. Семь конкретных фабрик: `SmartphoneFactory`, `LaptopFactory`, `TShirtFactory`, `JacketFactory`, `MilkFactory`, `BreadFactory`. Код, использующий фабрики, работает с типом `Product` и не зависит от конкретных классов.

**Почему не Abstract Factory:** товары независимы, связанных семейств объектов нет.

Паттерн даёт: инкапсуляцию логики создания, **Open/Closed** (новый товар = новая фабрика), единую точку изменения параметров товара.

### Паттерн: Iterator

`Warehouse` реализует интерфейс `Iterable<Product>` и возвращает встроенный `WarehouseIterator` с методами `hasNext()` и `next()`.

**Преимущество:** благодаря этому склад можно легко обходить стандартным циклом `for-each`.

Паттерн даёт: безопасный обход коллекции, **инкапсуляцию** внутренней структуры склада (скрывает, как именно хранятся товары — в массиве или списке). При вызове `next()` после конца обхода выбрасывается `NoSuchElementException`.

### Копирование и перемещение

`Warehouse(Warehouse other)` — копирующий конструктор, который реализует **глубокое копирование** склада. Клон сохраняет `id` оригинала, но получает собственные независимые копии объектов `Price`, `Quantity` и `Weight`.

**Перемещение:** метод `transferFrom(Warehouse other)` переносит объекты без копирования, полностью освобождая старый склад.

### Обработка ошибок

Ошибки сообщаются исключениями, вывод в консоль делает только.

| Ситуация                                     | Исключение                        |
|----------------------------------------------|-----------------------------------|
| отрицательная цена, количество или вес       | `IllegalArgumentException`        |
| остаток уходит в минус                       | `IllegalArgumentException`        |
| склад переполнен                             | `IllegalArgumentException`        |
| склад создан с размером меньше единицы       | `IllegalArgumentException`        |
| удаление товара с несуществующим ID          | `IllegalArgumentException`        |
| индекс за пределами списка                   | `IndexOutOfBoundsException`       |
| `next()` после конца обхода                  | `NoSuchElementException`          |

### Демонстрационные сценарии

1. **Создание склада.** Добавление товаров через разные фабрики, вывод списка через итератор.
2. **Копирование склада.** Изменение цены и остатка товаров в копии, проверка, что оригинал не изменился.
3. **Перемещение склада.** `transferFrom`, проверка, что товары не копируются (те же объекты).
4. **Поиск и удаление.** Поиск по ID, категории и цене, удаление по ID и по индексу, обработка ошибки при несуществующем ID.
5. **Перенос товара между складами.** `transferTo`, изменение цены и остатка, обработка ошибки при недопустимом остатке.
